# Courtvision

Courtvision is an NBA analytics project built around play-by-play data, machine learning, and automated game analysis.

The initial goal is to build a win-probability model that evaluates NBA games possession by possession and powers an automatically updating game intelligence dashboard.

## Planned Features

- NBA play-by-play data ingestion
- Game-state and possession-level feature engineering
- PyTorch win-probability modeling
- Win-probability charts
- Game turning-point detection
- Player impact analysis
- Automatically updating post-game dashboard
